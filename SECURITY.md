# Security

## Principles

- Webpage content and downloads are untrusted input.
- Browser state remains in the app container; downloads are Files-visible.
- Distributors own their signing, entitlements, and security review.

While this repository is private, collaborators should report a vulnerability through a private repository issue or an existing direct maintainer channel and clearly mark it as security-sensitive. Do not copy exploit details into a channel whose privacy is uncertain. Before any future public visibility change, the repository owner must enable GitHub private vulnerability reporting and verify that the **Report a vulnerability** action works; public issues must never contain exploit details. No response-time or support SLA is promised. Do not include credentials, browsing data, or personal details in reports. This source snapshot has no hosted backend or managed Apple entitlement.
