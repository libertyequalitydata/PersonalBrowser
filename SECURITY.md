# Security

## Principles

- Webpage content and downloads are untrusted input.
- Browser state remains in the app container; downloads are Files-visible.
- Distributors own their signing, entitlements, and security review.

Before publication, the repository owner must enable GitHub private vulnerability reporting and verify a test report can be received. Use the repository's **Report a vulnerability** action once it is enabled; do not post exploit details in a public issue. If that channel is unavailable, withhold the report and ask the repository maintainers for a private channel through a public issue containing no exploit or personal details. No response-time or support SLA is promised. Do not include credentials, browsing data, or personal details in reports. This source snapshot has no hosted backend or managed Apple entitlement.
