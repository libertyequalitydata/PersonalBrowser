# Code of Conduct

## Principles

- Treat contributors and users with respect.
- Discuss code and behavior without personal attacks or harassment.
- Protect private reports and personal information.

Harassment, discrimination, threats, or disclosure of private information are not accepted. Maintainers may remove contributions or participation that violate these rules. Before publication, repository maintainers must name and verify a private conduct-report channel in the repository contact settings or this document. Until then, ask maintainers through a public issue for a private contact without disclosing the concern there. This document creates no guaranteed moderation or response SLA.
