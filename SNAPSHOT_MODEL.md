# Snapshot model

## Principles

- Each release is an independently selected, cleaned, tested, and reviewed source snapshot.
- Older snapshot branches and tags stay immutable.
- A community-maintained continuation may use a separate branch or fork.

This source release is identified as snapshot `2026-10.1` and immutable tag `personal-browser-2026-10.1`. The public repository's `main` branch may continue to receive documentation, maintenance, and community changes after the tag. A later periodic source snapshot can be an unrelated code drop without shared ancestry, migration path, API compatibility, version continuity, or feature parity. There is no schedule and no promise to publish each commercial change. Builders may remain on this release or maintain derivatives under MIT.
