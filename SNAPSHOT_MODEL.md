# Snapshot model

## Principles

- Each release is an independently selected, cleaned, tested, and reviewed source snapshot.
- Older snapshot branches and tags stay immutable.
- A community-maintained continuation may use a separate branch or fork.

This snapshot is identified as `snapshot/2026-10` and `personal-browser-2026-10.1`. The source currently exists in a private repository; no tag, public release, binary, or distribution record is implied by these labels. A later snapshot can be an orphan code drop without shared Git ancestry, migration path, API compatibility, version continuity, or feature parity. There is no schedule and no promise to publish each commercial change. Builders may remain on this snapshot or maintain derivatives under MIT.
